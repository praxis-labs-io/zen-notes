# Start

One file per day, named for the date, in a directory you choose. No titles, no
folders, no tags. If a note needs a title it wants to be a document, and a
document is somebody else's program.

Sync is the storage directory's job. Point it at iCloud or Dropbox and the
problem belongs to them.

Three things to get right before anything else:

1. the note reaches disk without a save key
2. two terminals on the same day do not corrupt it
3. the cursor is never a lie
