# Scope

Saying no is most of the work.

Turned down so far:

- a config file, because the colours come from the terminal and the keys are
  vim's
- more than one note per day
- a note list or a sidebar, since `[` and `]` already walk the days
- anything that reaches the network

The bar is whether a person opening a terminal to write down one thing needs
it. **Most features fail that.**
