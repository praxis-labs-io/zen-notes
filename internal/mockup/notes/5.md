# Colour

No hardcoded hex. Everything is an ANSI slot so it inherits whatever the
terminal is set to, and the four derived colours shift the background's
lightness while keeping its hue.

Those four are the cursor line, the selection, the yank flash and the search
match. Everything else is a slot between zero and fifteen.

The background is queried at startup and again on focus, so a *mid-session*
theme switch is picked up. Some multiplexers never answer, so there is a
256-colour fallback and the default assumes dark.
