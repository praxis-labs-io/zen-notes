# Watcher

The watch has to be on the directory, not the file. An atomic save renames a
new inode over the target and a file watch follows the old one, which is why
the second terminal sat there showing stale text.

Fixed by moving the watch up one level. The goroutine owns its channel and
`waitForChange` reads it inside a command, so nothing outside `Update` ever
touches the model.

- two terminals, same day
- type in one, the other catches up inside a second
- edit both, confirm the dirty side keeps its edits
