# Render path

Kitty placeholders line up. The image sits under its line, and the cursor
still lands where the text says it should, which is the part I kept getting
wrong.

Build order is the whole thing. Styled runes, then wrapped rows, then the cursor. Every renderer bug I have had came from doing those in another order, and each one looked correct until a line was long enough to wrap.

![the render path](sketch.png)

> Wrapping, highlighting and the cursor have to agree. Anything that counts
> ANSI bytes as columns will look right and be wrong.

```go
func (e *Editor) Render(width int) Frame {
	rows := wrap(style(e.buf), width)
	return Frame{Rows: rows, Cursor: e.caret(rows)}
}
```

`GutterWidth` reads the line count, so the gutter shifts when the buffer
crosses ten lines. That wants a test.
