The navigation keys a keyboard has, now bound, and a day change that no
longer leaves the editor pointing at the note you came from.

## New

**Home, End, Page Up, Page Down and Delete work.** They were dropped silently in
every mode before. Home and End are motions, so counts, operators and visual
mode reach them: `d<End>` and `v<Home>` behave as `d$` and `v0`. Page Up and
Page Down move a screenful. Delete takes the rune under the caret in normal
mode, the rune ahead of it in insert mode where it also pulls the next line up
at the end of a line, and cuts the selection in visual mode.

**`--mockup` opens a set of sample notes instead of yours.** It seeds a
temporary directory, dated back from today, and removes it when you quit. It
refuses `--dir` and ignores `$ZEN_NOTES_DIR`, so it cannot reach your own notes
and nothing you type during a demo is kept. For screenshots and showing the
thing to somebody.

## Fixed

- Changing day from visual mode left the editor in visual mode, anchored into a
  note that was no longer open. It goes back to rest on a swap. Insert mode
  still survives one, so midnight arriving mid-sentence does not turn your next
  keystrokes into commands.
- The first thing typed on a note that arrived mid-insert can be taken back. The
  undo stack was cleared on the way in.
- The installer no longer warns that `git` is missing. zen-notes never asked for
  it.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/praxis-labs-io/zen-notes/main/install.sh | sh
```

macOS and Linux, arm64 and amd64, and no Go needed. It checks the download
against the release's checksums before it installs anything. Windows takes the
`.zip` from this page, the installer being a POSIX script. Anything else:

```sh
go install github.com/praxis-labs-io/zen-notes@v0.3.0
```

[Install in full](https://github.com/praxis-labs-io/zen-notes/blob/main/docs/install.md),
[the keymap](https://github.com/praxis-labs-io/zen-notes/blob/main/docs/keys.md),
and [the guide](https://github.com/praxis-labs-io/zen-notes/blob/main/docs/guide.md).

## Known gaps

- `pgup`, `pgdn`, `ctrl+d` and `ctrl+u` count logical lines rather than display
  rows, so a page through a wrapped paragraph travels further than one screen
  and keeps no overlap. Tracked.
- No Homebrew tap.
- Not in yet: `.` repeat, named registers, marks, macros, the jumplist.
